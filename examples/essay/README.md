## 先说天气

十月的第一个礼拜，山里一下子凉了。早上七点推开窗，雾还挂在对面的竹林上，像谁晾了一床没收的棉被。

我终于明白房东说的「这里只有两个季节：有雾的和更有雾的」是什么意思。

## 这个月做了的三件事

1. **把院子里那块荒地翻了一遍。** 种下萝卜、菠菜和一排小葱。邻居阿婆路过看了一眼，说萝卜种得太密，我假装没听见，然后在她走后偷偷拔掉了一半。
2. **学会了生炉子。** 第一次把整个屋子熏成了腊肉味，第三次终于能在十分钟内烧开一壶水。
3. **每天写五百字。** 不为什么，只是想知道一个人安静下来，到底能想多少东西。

## 关于孤独

很多朋友问我，一个人住在山上会不会孤独。

说实话，前两周会。晚上九点以后，世界安静得能听见冰箱压缩机启动的声音。后来我开始给每一样东西起名字：炉子叫「老周」，门口那棵柿子树叫「小满」，常来偷吃的那只橘猫叫「税务局」——因为它每天准时来收一次。

有了名字，好像就有了邻居。
