# 栖木笔记 · 更新日志

> 栖木笔记是一个虚构的本地优先笔记应用。这里记录每个版本的变化。
>
> 这是 Demox 的公开示例：把 `CHANGELOG.md` 发成深色、贴合开发者控制台风格的网页（dark 模板）。

## 3.4.0 · 2026-09-28

### 新增

- **双向链接面板**：在笔记右侧显示所有引用了当前笔记的地方，点击直接跳转。
- **每日笔记模板**：可以在设置里自定义，支持 `{{date}}` 和 `{{weekday}}` 变量。
- 命令面板新增「复制为 Markdown 链接」。

### 改进

- 打开 5000 篇以上的库时，首屏加载更快。
- 表格可以拖动列宽，宽度会被记住。
- 深色模式下代码块的对比度更高。

### 修复

- 修复在中文输入法下按回车会提前结束组合输入的问题。
- 修复导出 PDF 时图片偶尔丢失的问题。

## 3.3.2 · 2026-09-10

### 修复

- 修复同步冲突时可能生成重复文件的问题。
- 修复 Windows 上路径包含空格时附件无法打开的问题。

## 3.3.0 · 2026-08-22

### 新增

- **白板视图**：把笔记卡片拖到无限画布上自由排列。
- 支持 Mermaid 流程图。

### 变更

- 最低系统要求调整为 macOS 12 / Windows 10。
- 旧版「标签云」移到插件市场，不再内置。

## 3.2.0 · 2026-07-30

### 新增

- 全文搜索支持正则表达式。
- 快捷键可以完全自定义，并导出成 JSON。

### 改进

- 侧边栏折叠状态在重启后保留。

## 升级说明

从 2.x 升级的用户：首次启动会自动迁移索引，库越大用时越长，中途请不要关闭应用。迁移前会在库目录下生成 `.qimu-backup/`，确认无误后可以手动删除。
