# 封禁通知邮件：模板与发送口径

2026-10-17 定稿。phosa 拍板三项：**可上线**、**答复时限默认 3 个工作日**、**证据非必填**。

本文是发给用户的邮件原文，实现发送链路时从这里取，不要再手写一份。发送链路本身（触发时机、发信服务、退信与投诉回流）尚未实现，见需求 REQ-26。

## 发信前自检（不过不许发）

- 三要素齐全：站点 ID、停用原因、申诉入口
- 所有 `{{ }}` 已替换，无空值
- 不含内部角色名、系统名、IP、日志片段、内部链接
- 一封邮件只讲一个站点；多个站点被处理就分开发
- 不承诺具体解封时间，只写答复时限
- 停用原因取自下面「原因短语库」原文，不改写、不加戏

## 主题

```
【Demox】站点 {{站点ID}} 已停用，可申诉
```

```
[Demox] Site {{site_id}} has been suspended — appeal available
```

## 正文（中文）

```
你好：

我们在对平台站点做内容复核时，你的站点 {{站点ID}}（{{站点名称}}）已被停用，目前访问返回 403。

停用原因：{{停用原因}}

影响范围：
1. 该站点对外访问已关闭（HTTP 403）；
2. 站点数据未删除，处理完成后可以恢复。

如果你认为这次处理有误，或者已经完成整改，可以申诉：
1. 直接回复本邮件，或发到 phosa@qq.com；
2. 标题写明「申诉 + 站点 ID」；
3. 正文附上站点 ID、你的账号邮箱，以及整改说明（如果已完成整改）。

我们在收到申诉后 {{答复工作日}} 个工作日内答复。

Demox
```

## 正文（English）

```
Hello,

While reviewing sites on Demox, we suspended your site {{site_id}} ({{site_name}}).
It now returns HTTP 403.

Reason: {{reason}}

What this means:
1. The site is no longer publicly reachable;
2. Site data has not been deleted and can be restored once this is resolved.

If you believe this was a mistake, or you have already fixed the issue, you can appeal:
1. Reply to this email, or write to phosa@qq.com;
2. Put "Appeal + site ID" in the subject;
3. Include the site ID, your account email, and what you changed (if applicable).

We reply within {{reply_days}} business days.

Demox
```

## 变量

| 变量 | 取值来源 | 填法 |
| --- | --- | --- |
| `{{站点ID}}` / `{{site_id}}` | 站点记录，或站点链接 `/sites/<id>` 里那一段 | 原样填，不改大小写、不加前缀、不缩写 |
| `{{站点名称}}` / `{{site_name}}` | 用户创建站点时填的名字 | 没有就写「你的站点」/ 英文写 `your site`，不留空 |
| `{{停用原因}}` / `{{reason}}` | 下面「原因短语库」 | 只抄原文，不自己写原因 |
| `{{答复工作日}}` / `{{reply_days}}` | 全平台统一值，固定 3 | 不逐封调整 |

可选：证据。只在有用户自己能核对的可见证据时附（例如出问题的页面 URL），不主动补截图。

## 原因短语库（对外措辞）

原则：说清违反了哪一条，但不复述敏感内容本身、不引用词表条目、不透露审核机制。按《服务条款》第六节的处理档位对应：

| 对外说法（直接抄） | 对应处理档位 | 什么情况用 |
| --- | --- | --- |
| 站点内容违反《服务条款》第四节「禁止及重点审核内容」，相关内容已下线 | 限制访问 / 下线 | 自动审核或人工复核命中违规内容 |
| 站点被用于分发违反《服务条款》的内容，已停用 | 冻结 / 封禁 / 删除 | 恶意或有害程序、侵权与品牌滥用、违规营销等较重情形 |
| 账号相关功能受限，站点随之停用 | 限制账号功能 | 反复违规、影响面较大 |

第六节还有「向有关主管部门报告」一档：**不走本邮件告知，不写进模板。**

## 申诉入口

- 直接回复本邮件
- `phosa@qq.com`（《服务条款》「九、联系我们」写的就是这个）
- 站内反馈渠道

申诉必收：站点 ID、账号邮箱、整改说明（可选）。对方没给站点 ID 的，回一封要 ID，不要凭猜测处理。

## 故意不写的东西

- 不写解封时间，不写「不影响账号」这类承诺
- 不写规则细节（词表、阈值、审核模型），避免被反试探
- 不写内部系统名、数据库字段、函数名、IP、日志片段
- 不写「永久封禁」，除非明确要求永久

## 依据

措辞取自 `src/pages/terms.tsx`：《服务条款》第三节（自动审核）、第四节（禁止及重点审核内容）、第六节（违规处理，四档）、第九节（联系我们）。后端没有封禁原因枚举，故本文件用档位说法，不自造原因码。
